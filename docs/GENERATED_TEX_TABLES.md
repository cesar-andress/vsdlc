# Generated table outputs (no LaTeX)

Canonical reproducibility outputs are **JSON/CSV** under `data/processed/`.
This package does **not** ship `.tex` files.

| Output | Generated by | Role |
|---|---|---|
| `data/processed/human_only_consensus_sensitivity.json` | `scripts/analyze_human_only_consensus_sensitivity.py` | RQ1 human-only / protocol sensitivity |
| `data/processed/llm_third_adjudicator_audit.json` | `scripts/analyze_llm_third_adjudicator.py` | LLM tie-break accounting |
| `data/processed/target_sensitivity_results.json` | `scripts/analyze_target_sensitivity.py` | Target-collapse sensitivity |
| Dual-inspector metrics | `scripts/evaluate_second_inspection.py` | RQ4 inspection diagnostic (JSON/CSV paths in script docs) |

Optional `.tex` dumps from scripts (if regenerated locally) are gitignored and must not be committed.
Manuscript sources live only in the local parent tree.
