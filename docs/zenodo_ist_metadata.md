## Description (paste into Zenodo)

Frozen replication package for a labelled empirical study of public GitHub repositories retrieved by AI-instruction filename and path searches within one eligible labelled frame (companion PeerJ Computer Science manuscript).

The archive contains:

- A reproducible GitHub audit protocol (discover, filter, annotate, inspect)
- Frozen study datasets and annotation worksheets
- Analysis scripts for sensitivity tables, predicate-family composition, concordance, and secondary inspection comparison
- JSON/CSV outputs for independent replay

Replication material only: no manuscript LaTeX, PDFs, bibliographies, or editorial documents.
